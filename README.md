# Habit Calendar Tracker

A simple habit tracker built with HTML, CSS, and JavaScript.

This app lets users add daily habits, check completed days, and visualize streaks in a calendar-style layout.

## Features

- Add and delete habits
- Check completed days
- View daily streaks
- Calendar-style habit history
- Mobile-friendly design

## Future Improvements

- Monthly calendar view
- Local storage support
- Daily habit summary
- PWA support
- Habit editing
